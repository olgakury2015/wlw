TCP 推送（连平台）

对端脚本作 TCP 客户端，连接运行本平台的机器上可被访问的 IP 与端口 9099（iot.tcp.port），每行一条 UTF-8 JSON； 字段 device_id 或 deviceId 与本页设备编号一致时会上线并入库。

MQTT 接入（平台 = 订阅者）

若上方档案中填写了 MQTT Broker 与订阅主题，平台会按该配置单独连接并订阅；未填写时仅使用 application.yml 的 iot.mqtt（含多路 brokers）。 本设备在固件中应作为发布者，向与你约定一致的主题发消息（常见 …）；负载中 deviceId / device_id 与本页设备编号一致。 独立连接入库的遥测带 mqttPerDevice=true。

当前 iot.mqtt.enabled=false 仅表示 yml 全局 MQTT未启用；本设备已填写 Broker 与订阅主题时，平台仍会按档案独立连接 Broker，与该开关无关。收不到数据时请查服务端日志是否出现 MQTT[设备 …] 已连接 / 已订阅，或 连接失败 及原因。

当前 iot.mqtt.enabled=false，且本设备未配置独立 Broker，平台不会通过 MQTT 收数。请在档案填写 Broker + 订阅主题，或启用全局 iot.mqtt。
