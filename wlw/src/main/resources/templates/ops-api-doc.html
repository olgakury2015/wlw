HTTP API 说明

以下为平台对外常用接口摘要。基础路径与端口以当前部署为准（本页相对路径以站点根为前缀）。

健康检查

GET /api/v1/health — 无需认证，供负载均衡或外部探活。

设备遥测上报

POST /api/v1/telemetry — Content-Type: application/json，无需浏览器会话。

{
  "deviceId": "与平台设备编号一致",
  "protocol": "HTTP",
  "payload": { "temp": 25.5, "hum": 60 }
}

最近遥测查询（API 密钥）

GET /api/v1/telemetry/recent — 请求头增加 X-Api-Key: <明文>。 密钥在「运维与安全 → API 密钥」由管理员创建；服务端仅存 SHA-256，请自行保管明文。

控制台会话（Cookie）

管理类接口（如创建设备、导出部分能力）需在浏览器登录后携带会话 Cookie，且需 ADMIN 角色。 只读用户 USER 可查看设备、数据与仪表板等，不可改配置。

数据中心导出（登录后）

在「数据中心 → 时序查询与导出」中按设备与时间筛选后，可下载 GET /data/export.csv 或 GET /data/export.xlsx（Excel），参数：deviceSn、from、to（与页面 datetime-local 格式一致）。
