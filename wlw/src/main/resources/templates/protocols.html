协议接入说明

以下为平台侧能力摘要，具体地址与端口以 application.yml 为准。

HTTP

REST JSON 写入遥测，适合网关、Node-RED HTTP Request、第三方系统回调。

POST /api/v1/telemetry
POST /api/v1/http/ingest

TCP（平台作服务端）

设备或脚本作客户端连接下方地址，每行一条 UTF-8（常以 \n 结尾的 JSON）。字段 deviceId / device_id / deviceSn 与控制台「设备编号」一致时可标在线。与 TCP_PULL（平台主动连设备）可同时使用。

监听

MQTT

平台连接 Broker 后订阅上行主题（如 wlw/devices/+/telemetry）接设备数据；入库后可选扇出发布到 wlw/platform/telemetry/ + 设备编号（见 yml：publish-topic-prefix、fanout-sub-topic-prefix），便于本机脚本只订阅消费。

MQTT

Modbus TCP

读保持寄存器、输入寄存器、线圈。

POST /api/v1/modbus/tcp/read-holding
POST /api/v1/modbus/tcp/read-input
POST /api/v1/modbus/tcp/read-coils

Modbus RTU / RS485

经串口的 RTU 帧（j2mod）。启用前请确认 COM 口与接线。

RTU
POST /api/v1/modbus/rtu/read-holding

默认 Modbus TCP 目标

请求体中可覆盖 host/port/unitId。

127.0.0.1:502
